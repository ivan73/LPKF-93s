# LPKF LMD 3.0 – Dateiformat

Reverse-engineered aus einer Exportdatei von **CircuitCAM 4.0 (414c)** für **BoardMaster 5.1**.
`lpkf93s/lmdio.py` liest und schreibt das Format. Eine CircuitCAM-Datei wird damit byte-genau reproduziert.

## Aufbau

```
ASCII-Kopf        Zeilen mit "\n\r" (0A 0D!) getrennt
0x1A              Ende des Kopfes
Größentabelle     0x0B <opcode> <int32 Bytes>   je Befehl, in dieser Reihenfolge:
                  0C:8  0D:8  0E:12  0F:8  10:4  11:20  11:20 (sic, doppelt)
Phasenblöcke      beliebig viele, bis Dateiende
```

Kopf, wie CircuitCAM ihn schreibt:

```
LPKF_Mill_Drill File (LMD) Version 3.0
Generated by: CircuitCAM Version 4.0 (414c), S/N: …
User: …
Organization:
Location:
```

## Phasenblock

```
82 81                      Phasenbeginn
07 <Phasenname> 00         z.B. MillingTop, DrillingPlated, CuttingOutside
07 <Layername>  00         z.B. InsulateTop, DrillPlated, CuttingOutside
00
  Werkzeuge (beliebig viele):
  80
  03 <int32 Nummer>        1-basiert, Nummer innerhalb der Phase
  01 <byte Typ>            0 = Fräser, 1 = Bohrer
  05 <float32 Ø in m>
  07 <Name> 00             muss zur BoardMaster-Werkzeugbibliothek passen
  00
  Befehle (beliebig viele):
00                         Phasenende
```

## Befehle

Alle Koordinaten sind **float32 little-endian in Metern**, im Koordinatensystem der Gerber-Daten.
Die Lötseite wird **nicht** gespiegelt, das macht BoardMaster.

| Opcode | Parameter | Bedeutung |
|---|---|---|
| `10` | int32 n | Werkzeug n der Phase wählen |
| `0C` | x, y | Fahren ohne Fräsen zu (x, y), dort absenken (Bahnbeginn) |
| `0D` | x, y | Linie nach (x, y) |
| `11` | x, y, cx, cy, r | Bogen nach (x, y) um Mittelpunkt (cx, cy); r > 0 gegen, r < 0 im Uhrzeigersinn |
| `0F` | x, y | Bohrung |
| `0E` | 12 Byte | in der Größentabelle deklariert, im Beispiel nicht benutzt |

## Phasen in der CircuitCAM-Vorlage „DoubleSided“

MillingTop (InsulateTop, BoardOutline, TextTop), MillingBottom (InsulateBottom, BoardOutline, TextBottom),
DrillingPlated, DrillingUnplated, Dispense, Vacuum, CuttingOutside, CuttingInside,
CuttingSoldStopTop/Bottom, MarkingDrills (DrillPlated, DrillUnplated), DispenseSolderPasteTop/Bottom.

Beobachtungen aus der CircuitCAM-Ausgabe:
* Bohrungen über 2,4 mm: `0C` Mitte, `0D` nach links auf Radius (Loch − Fräser)/2, zwei Halbbögen mit r > 0.
* Außenkontur: Fräsermitte um den Fräserradius nach außen versetzt, gegen den Uhrzeigersinn.
* Koordinaten sind auf 5 µm gerastert. gerber2lmd schreibt ungerastert – ob BoardMaster das ohne Weiteres annimmt, ist auf der Maschine noch zu bestätigen.
